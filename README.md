# adsManager

광고를 만들고 운영하는 일을 더 빠르게 할 수 있도록 만든 광고 관리 대시보드예요.

전문 지식이 없어도 캠페인을 만들고, 성과를 확인하고, 필요한 수정까지 직접 할 수 있어요.
대행사나 마케터의 답변을 기다리지 않아도 필요한 변경을 바로 확인하고 적용할 수 있도록 만들었어요.

## 캠페인을 만들어요

구매, 앱 설치, 리드, 방문 같은 목표를 정하고 업종, 예산, 타겟을 설정해서 캠페인을 만들 수 있어요.

머니알림, 행운퀴즈, 버튼 누르기 같은 리워드 상품도 선택할 수 있어요.
현재 운영 중인 캠페인의 성과와 전환 데이터를 기준으로 어떤 상품이 더 잘 맞을지 점수를 계산해 추천해줘요.

처음부터 모든 항목을 직접 입력할 필요는 없어요.
원하는 캠페인을 문장으로 설명하면 AI가 초안을 만들어주고, 필요하면 타겟이나 세부 설정을 이어서 조정할 수 있어요.

## 물어보고, 확인하고, 적용해요

화면 오른쪽 아래에는 캠페인 운영을 돕는 어시스턴트가 있어요.

성과가 좋은 캠페인을 찾거나, 예산 조정이 필요한 캠페인을 물어볼 수 있어요.
캠페인 일시정지나 예산 변경 같은 작업도 제안받을 수 있어요.

다만 AI가 설정을 바로 변경하지는 않아요.
변경 내용은 항상 먼저 제안하고, 사용자가 직접 확인한 뒤 적용해요.

예산 역시 한 번에 크게 변경하지 않고, 정해진 범위 안에서만 조정을 제안하도록 했어요.

## 전환도 직접 찾아줘요 (구현 예정)

사이트에 있는 폼, 버튼, 링크를 분석해서 실제 전환으로 볼 수 있는 행동을 찾아요.

어떤 요소를 추적해야 할지 직접 설정하지 않아도 페이지를 분석해 전환 후보와 추적 규칙을 제안해줘요.

광고를 통해 들어온 사용자는 UTM 정보를 기준으로 어떤 매체에서 유입됐는지 구분해요.
매체별 UTM 규칙을 파악해 유입 수를 측정하고, 이후 캠페인 성과와 전환 데이터를 함께 비교할 수 있도록 만들 예정이에요.

## 브라우저에서 바로 실행되는 AI를 사용해요

adsManager의 AI는 외부 AI 서버를 호출하지 않아요.

Chrome에 내장된 온디바이스 AI를 사용해서 사용자의 브라우저 안에서 처리해요.
별도의 모델 API 비용이 들지 않고, AI 처리를 위해 데이터를 외부 서버로 보낼 필요도 없어요.

현재 온디바이스 모델은 한국어를 직접 지원하지 않아서 한국어 입력을 영어로 번역한 뒤 모델에 전달하고, 응답을 다시 한국어로 변환해 보여줘요.

Chrome에서 온디바이스 AI를 사용할 수 없는 경우에는 규칙 기반 응답으로 대체해요.
현재 어떤 방식으로 답변하고 있는지도 화면에서 확인할 수 있어요.

## 아직 구현 못한 부분도 있어요

현재는 하나의 광고 계정을 기준으로 동작해요.
로그인과 사용자별 계정 분리는 아직 구현하지 않았어요.

실제 광고 매체 API도 아직 연결하지 않았어요.
대신 테스트 데이터를 직접 넣어서 캠페인 성과에 따라 추천과 예산 조정 로직이 어떻게 반응하는지 검증하고 있어요.

## 이렇게 만들었어요

Next.js로 웹 앱을 만들고, Cloudflare D1에 데이터를 저장해요.

캠페인 목록처럼 자주 조회하는 데이터는 캐싱해서 불필요한 요청을 줄였어요.
그리고 과도한 AI사용보단 적절하게 필요한 부분을 세분화하여 과도한 로딩, 잘못된 대답을 하는 경우를 줄였어요.
